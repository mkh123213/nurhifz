# ملخص مشروع نور حفظ (Nur Hifz)

## نبذة عامة

**نور حفظ** هو تطبيق لإدارة حلقات تحفيظ القرآن الكريم، يهدف إلى مساعدة المعلمين في متابعة طلابهم وتتبع تقدمهم في الحفظ والمراجعة. يتكون المشروع من نسختين:

1. **تطبيق موبايل (Flutter)** — يستخدم Firebase كقاعدة بيانات، و Bloc/Cubit لإدارة الحالة
2. **تطبيق ويب (React)** — مبني على منصة Base44 مع Vite و TailwindCSS

---

## الميزات الحالية

### إدارة الطلاب
- إضافة وتعديل بيانات الطلاب (الاسم، العمر، رقم الهاتف، المستوى، الملاحظات)
- تصنيف الطلاب حسب المستوى: مبتدئ، متوسط، متقدم
- تفعيل/تعطيل حالة الطالب

### تتبع تقدم الحفظ
- تسجيل الأجزاء المحفوظة (من 0 إلى 30 جزء)
- تسجيل الصفحات المحفوظة (من 0 إلى 604 صفحة)
- تحديد الأهداف لكل طالب
- عرض آخر جلسة تسميع

### جلسات التسميع
- نوعان: حفظ جديد (hifz) ومراجعة (muraja'a)
- تحديد السورة ونطاق الآيات (من آية - إلى آية)
- تقييم بالدرجات (0-100)
- تسجيل الأخطاء والملاحظات

### الحضور والغياب
- تسجيل يومي: حاضر، غائب، معذور
- عرض ملخص الحضور
- اختيار التاريخ

### لوحة المعلومات (Dashboard)
- إحصائيات عامة
- شبكة إحصائيات سريعة
- قسم تقدم الحفظ
- آخر الجلسات
- إجراءات سريعة

### التقارير
- رسوم بيانية للدرجات
- رسوم بيانية لتقدم الأجزاء
- توزيع المستويات (رسم دائري)
- جدول تفصيلي

### المصادقة
- تسجيل دخول / إنشاء حساب
- استعادة كلمة المرور

### الإعدادات
- تبديل المظهر (فاتح/داكن)
- تفضيلات المستخدم

### الرسائل
- نظام مراسلات بين المعلم والطلاب/أولياء الأمور
- إشعارات وتذكيرات

## نصائح لتطوير وتحديث التطبيق

### 1. تحسين تجربة المستخدم
- اضافة **وضع عدم الاتصال (Offline Mode)** حتى يتمكن المعلم من تسجيل الحضور والجلسات بدون إنترنت ومزامنتها لاحقا
- إضافة **إشعارات فورية (Push Notifications)** لتذكير الطلاب بمواعيد الحلقات
- إضافة **بحث وفلترة متقدمة** في قائمة الطلاب (حسب المستوى، الحضور، التقدم)

### 2. ميزات تعليمية جديدة
- إضافة **خطة حفظ ذكية** تقترح جدول حفظ لكل طالب بناء على مستواه وسرعته
- إضافة **تتبع التجويد** مع تصنيف الأخطاء (تجويد، حفظ، ترتيل)
- إضافة **نظام مكافآت وشارات** لتحفيز الطلاب
- إضافة **تسجيل صوتي** للجلسات حتى يتمكن الطالب من مراجعة أدائه

### 3. التواصل مع أولياء الأمور
- إضافة **تقارير تلقائية** ترسل لأولياء الأمور أسبوعيا عبر واتساب أو البريد الإلكتروني
- إضافة **لوحة خاصة بولي الأمر** لمتابعة تقدم ابنه مباشرة
- تفعيل **الإشعارات عند الغياب** المتكرر

### 4. تحسينات تقنية
- إضافة **اختبارات (Unit & Widget Tests)** لضمان جودة الكود
- تطبيق **Firestore Security Rules** صارمة لحماية البيانات
- إضافة **تخزين مؤقت (Caching)** لتقليل قراءات Firestore وتحسين الأداء
- تطبيق **CI/CD** عبر GitHub Actions و Fastlane لأتمتة النشر
- إضافة **Firebase Crashlytics** لتتبع الأعطال

### 5. ميزات إدارية
- إضافة **إدارة متعددة الحلقات** بحيث يمكن لمشرف واحد متابعة عدة معلمين
- إضافة **تصدير التقارير** بصيغة PDF أو Excel
- إضافة **إحصائيات مقارنة** بين الفصول والفترات الزمنية
- إضافة **نظام صلاحيات** (مدير، معلم، ولي أمر)

### 6. تحسين واجهة المستخدم
- إضافة **رسوم متحركة (Animations)** لجعل التنقل أكثر سلاسة
- دعم **الوضع الأفقي (Landscape)** للأجهزة اللوحية
- تحسين **التصميم المتجاوب** ليعمل بشكل ممتاز على جميع أحجام الشاشات
- إضافة **ثيمات ألوان متعددة** يختار منها المعلم

### 7. توسيع المنصة
- نشر التطبيق على **App Store** بالإضافة إلى Google Play
- تطوير **نسخة ويب كاملة** متكاملة مع تطبيق الموبايل
- إضافة دعم **لغات إضافية** (أوردو، تركي، إندونيسي) للوصول لشريحة أوسع
